# Outils de validation

- [Générateur d'images](generateur-images-tests.md) : exports IPR par groupe,
  neutres et manifeste de réglages ; n'analyse pas les images.
- [Analyseurs par groupe](analyseurs-groupes.md) : TIFF 16 bits natifs,
  associations explicites, audits et JSON immuables ; ne génèrent ni ne
  suppriment d'images et ne décident pas d'une acceptation visuelle.
- [Protocoles](../protocols/README.md) et [procédure autonome](../procedure-tests-autonomes.md)
  : recette, interprétation et clôture.
