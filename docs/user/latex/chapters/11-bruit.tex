\chapter{Réduction du bruit}
\section{Commande globale et réglages avancés}
Le curseur \emph{Réduction du bruit} va de 0 à 100, avec zéro comme référence.
Il commande ensemble luminance et couleur, avec une progression différente
pour chaque composante. Ce n'est pas une échelle équivalente à celle de Lightroom.
Ouvrir \emph{Avancé} pour régler séparément les deux composantes.
Une combinaison indépendante peut afficher \emph{Perso.} sur la commande globale.

\section{Séparer deux composantes}
\emph{Bruit de luminance} agit sur les fluctuations de clarté ;
\emph{Bruit de couleur} vise les variations chromatiques parasites.
Les deux contrôles vont de 0 à 100, référence zéro. Leur présence ne signifie
pas que le moteur utilise une IA équivalente à celle d’un autre logiciel.

\section{Chemin RAW expérimental}
La case \emph{Signal RAW signé, avant les profils (expérimental)} est désactivée
par défaut. Elle sélectionne, pour un RAW et un contexte caméra compatibles,
un débruitage avant les corrections optiques et le rendu DCP. Le changement
peut nécessiter un redécodage. Sans contexte compatible, le chemin classique
reste utilisé ; la case seule n'atteste donc pas du chemin effectif.
Cette sélection est un état de session, pas une option garantie persistée
dans le sidecar. Les forces et cette sélection ne doivent pas être confondues.
Le prototype courant n'est pas neuronal. Sa stabilisation ne signifie pas
qu'il préserve parfaitement tous les détails ; la piste neuronale est prévue
pour la bêta, pas disponible dans cette version.

\section{Méthode d’utilisation}
Corriger d’abord l’exposition utile et examiner une zone sombre relativement
uniforme, puis une zone texturée. Augmenter progressivement la réduction
de couleur si des taches colorées sont visibles. Ajuster ensuite la luminance
en vérifiant les cheveux, le tissu ou les détails fins. Revenir en vue ajustée
pour juger la sensation globale.

\paragraph{Exemple.}
Sur une photo à ISO élevés, ne pas conclure à partir du seul fond sombre.
Comparer également une texture et un contour net. Utiliser \touche{Ctrl + 1}
en gardant à l’esprit la résolution de l’aperçu, puis vérifier un export pleine
résolution pour une décision finale sur le détail.

\attention{Un débruitage plus fort peut supprimer de vrais détails.
Une référence Lightroom obtenue avec débruitage IA ne constitue pas une
comparaison à algorithmes identiques.}
