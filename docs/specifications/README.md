# Spécifications fonctionnelles

Une spécification décrit le comportement attendu, les limites et les critères d'acceptation d'une fonctionnalité. Elle ne contient ni une trace exhaustive de développement ni des mesures brutes.

- [Réglages photographiques](reglages-photographiques.md)
- [Zoom, navigation et comparaison dans l'aperçu](zoom-image.md)

Les fonctionnalités non commencées (recadrage/géométrie, masques locaux et IA) doivent obtenir leur propre spécification avant implémentation. La première version de débruitage et netteté est documentée dans [l'architecture](../architecture/denoising-sharpening.md) et attend sa validation photographique.
