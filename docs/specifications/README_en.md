# Functional Specifications

A specification describes the expected behavior, limits, and acceptance criteria of a feature. It contains neither an exhaustive development trace nor raw measurements.

- [Photographic Adjustments](reglages-photographiques.md)
- [Zoom, Navigation, and Comparison in Preview](zoom-image.md)

Features not yet started (cropping/geometry, local masks, and AI) must obtain their own specification before implementation. The first version of denoising and sharpening is documented in [the architecture](../architecture/denoising-sharpening.md) and awaits its photographic validation.
