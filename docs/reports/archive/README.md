# Archive de rapports

Ce répertoire reçoit les rapports historiques qui ont été consolidés dans une spécification, une analyse de validation ou un ADR. Un rapport archivé conserve sa date et ses liens de preuve.

- [technical/](technical/) : rapports de développement, architecture, compatibilité et performance.
- [exports/](exports/) : états exportés par les outils de travail.
